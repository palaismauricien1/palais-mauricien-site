## 1. Google Search Console
**Lien direct** : https://search.google.com/search-console/welcome

1. Login avec `palaismauricien@gmail.com`
2. "Ajouter une propriété" → **Préfixe d'URL**
3. Saisir : `https://www.palaismauricien.re/`
4. Méthode de validation recommandée : **Balise HTML** → Google te donne un code du type `<meta name="google-site-verification" content="ABC123..." />`
5. **Envoie-moi ce code** par message — je l'ajoute dans le `<head>` de toutes les pages, je push, et tu cliques "Vérifier" dans la console (≈ 1 min après le déploiement)
6. Une fois validé : **Sitemaps** → ajouter `sitemap.xml` → soumettre
